# Trilhas de fundo dos vídeos

Coloque aqui arquivos de música **royalty-free** (`.mp3`, `.m4a`, `.aac`, `.wav`, `.ogg`).

- O pipeline de vídeo escolhe **uma faixa aleatória** desta pasta e mixa por baixo da
  narração, em volume baixo (`INSTAGRAM_VIDEO.MUSIC_VOLUME`), em loop, cortada no fim da fala.
- **Sem nenhum arquivo aqui, o vídeo sai só com a narração** (sem erro).
- O caminho é configurável por `INSTAGRAM_MUSIC_DIR` (relativo ao diretório da API ou absoluto).

Não versione faixas com direitos autorais.
